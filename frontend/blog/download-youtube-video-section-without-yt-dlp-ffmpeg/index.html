How to Download a Specific Section of a YouTube Video (Browser vs. yt-dlp & FFmpeg)

Published by YTCuttr Team • 6 min read

Developers and power users on forums like GitHub Gists, r/DataHoarder, and r/pythontips frequently discuss how to download only a specific time-slice of an online video without downloading the full multi-gigabyte recording.

In this guide, we break down how to accomplish this using both methods: Method 1 (Command-Line with yt-dlp & FFmpeg) for automated scripting, and Method 2 (1-Click Web Tool with YTCuttr) for instant browser-based downloads on any device.

Method 1: The Command-Line Way (yt-dlp + FFmpeg)

If you have a terminal environment with Python, yt-dlp, and ffmpeg installed in your PATH, yt-dlp features a native --download-sections argument that downloads only the target segment:

yt-dlp --download-sections "*00:01:30-00:03:00" --force-keyframes-at-cuts -f "bv*[ext=mp4]+ba[ext=m4a]/b[ext=mp4]" "https://www.youtube.com/watch?v=VIDEO_ID"

Alternatively, if you already have a full video on disk and want to trim a slice without re-encoding quality loss, you can run FFmpeg with stream copy mode:

ffmpeg -ss 00:01:30 -to 00:03:00 -i full_video.mp4 -c copy trimmed_clip.mp4

Drawbacks of the Command-Line Approach

  • Requires installing Python, pip, yt-dlp, and FFmpeg binary packages.
  • Frequent breakages when YouTube changes signature ciphers, requiring manual updates via yt-dlp -U.
  • Cannot be used on smartphones (iPhones or standard Android devices) or restricted work laptops.
  • Requires guessing timestamps or playing the video in another window to write down exact seconds.
